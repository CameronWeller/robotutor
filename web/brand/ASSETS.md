The Robotutor mark comes from OLMS-V2 at commit 30cf0f2709d49727564577c1fe91ebf9763e4b14, in `identity/robotutor/assets/robotutor-logo.svg`. The tile, R and dot use the desktop palette. The paths and transforms are preserved. The PNG is a rasterization of this SVG for the native window and taskbar.

Nunito is bundled from the Google Fonts repository at commit 06bfe0d62a98375cb09c942fa18e68bd32cff057, in `ofl/nunito/Nunito[wght].ttf`. Its license accompanies the font in OFL.txt.

The Rust renderer embeds the 400 and 700 weight instances of this same font in desktop/native/assets. They were generated with fontTools varLib.instancer using the named weight and --update-name.
